# 高校财务问答数据集

数据集围绕高校财务制度、服务指南与审批材料构建，包含86篇材料和349道问答。材料于2026年4月从东北大学公告收集；问答由一位专业高校会计师依据业务需求编写，再由另一位会计师与四位计算机科研人员逐题审核。

| 文件 | 内容 |
| --- | --- |
| [corpus.json](corpus.json) | 86篇材料的标题、类别与正文 |
| [qa.json](qa.json) | 349道问题、参考答案、题型与证据标注 |
| [catalog.json](catalog.json) | 材料索引、标题、类别与正文字数 |
| [metadata.json](metadata.json) | 数据规模、类别统计与文件校验值 |

问答包含查询207道、判断99道、推理43道。每条问答通过 `evidence_list` 保存证据标题与标注内容，标题对应 `corpus.json` 中的材料。

材料类别包括服务指南37篇、审批表格29篇、校内规章制度18篇，另有类别为空和标为“未分类”的材料各1篇。

运行时以全部86篇材料为检索范围。字段定义见[数据说明](../docs/data.md)。
